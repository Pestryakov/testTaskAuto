## BUG-01 — После редактирования задачи обновляется не тот элемент в списке

**Severity:** Critical  
**Приоритет:** High  
**Компонент:** Редактирование задачи

**Описание:**  
JSONPlaceholder при POST-запросе всегда возвращает фиксированный `id: 201` для любой новой задачи. Код ищет задачу по `id` для замены в массиве через `findIndex`. При добавлении двух и более задач все они получают одинаковый `id: 201`, что вызывает коллизию — при редактировании обновляется первая найденная запись с этим ID, а не та которую редактировал пользователь.

**Шаги воспроизведения:**
1. Открыть приложение, открыть DevTools → Network
2. Добавить задачу «Task A» → убедиться что в Network ответ содержит `"id": 201`
3. Добавить задачу «Task B» → убедиться что ответ тоже содержит `"id": 201`
4. Нажать Edit у «Task B», изменить на «Task B edited», нажать Save

**Фактический результат:** Обновляется «Task A» (первая с id=201), а не «Task B»

**Ожидаемый результат:** Обновляется именно та задача которую редактировал пользователь

**Окружение:** Chrome, localhost:4200

## BUG-02 — Нет обработки ошибок при недоступности API

**Severity:** Major  
**Приоритет:** Medium  
**Компонент:** Все операции с задачами

**Описание:**  
В сервисе `TodoService` и компоненте `TaskListComponent` отсутствует обработка ошибок для всех HTTP-запросов. При потере соединения после загрузки страницы пользователь не получает никакой обратной связи — кнопки не реагируют, задачи не добавляются/удаляются без объяснения причины.

**Шаги воспроизведения:**
1. Открыть приложение — страница загружается нормально
2. DevTools → Network → переключить на «Offline»
3. Попытаться добавить задачу

**Фактический результат:** Ничего не происходит, нет сообщения об ошибке

**Ожидаемый результат:** Отображается сообщение «Не удалось выполнить операцию. Проверьте подключение к сети»

## BUG-03 — Отсутствует адаптация под мобильные устройства

**Severity:** Major  
**Приоритет:** Medium  
**Компонент:** UI / Вёрстка

**Описание:**  
Приложение не имеет адаптивной вёрстки для мобильных устройств. Элементы интерфейса отображаются некорректно на узких экранах: кнопки выходят за границы экрана, текст обрезается, кнопки Edit/Delete/Save слишком маленькие для нажатия пальцем.

Дополнительно: кнопки фильтров All/Active/Completed визуально слабо различимы между собой — активная кнопка отличается только цветом фона, что недостаточно для удобного UX. Рекомендуется сделать активную кнопку более контрастной (другой цвет + жирный шрифт или обводка).

**Шаги воспроизведения:**
1. Открыть приложение в DevTools → Toggle Device Toolbar (Ctrl+Shift+M)
2. Выбрать любое мобильное устройство (например iPhone 12)

**Фактический результат:** Кнопки и элементы списка отображаются некорректно, интерфейс неудобен для использования на мобильном

**Ожидаемый результат:** Интерфейс корректно адаптируется под мобильные экраны, все кнопки доступны и удобны для нажатия

**Окружение:** Chrome DevTools Mobile View, localhost:4200

## BUG-04 — TypeError на сервере при отметке галочкой новодобавленной задачи

**Severity:** Critical  
**Приоритет:** High  
**Компонент:** Обновление задачи / API

**Описание:**  
При добавлении новой задачи JSONPlaceholder возвращает `id: 201` (фиксированный ID для всех POST-запросов). Эта запись реально не существует в базе JSONPlaceholder. При попытке обновить такую задачу (отметить галочкой или отредактировать) отправляется PUT-запрос на `/todos/201`, что вызывает на сервере `TypeError: Cannot read properties of undefined (reading 'id')`.

**Шаги воспроизведения:**
1. Открыть приложение
2. Добавить новую задачу «Test task»
3. Нажать на чекбокс у этой задачи
4. Открыть DevTools → Network → посмотреть ответ на PUT запрос

**Фактический результат:** Сервер возвращает ошибку:
```
TypeError: Cannot read properties of undefined (reading 'id')
    at update (json-server/lib/server/router/plural.js:262:24)
```

**Ожидаемый результат:** Задача корректно обновляется, ошибок на сервере нет

**Причина:** JSONPlaceholder возвращает `id: 201` для всех новых задач, но реально не сохраняет их — PUT на несуществующий ID вызывает краш

**Окружение:** Chrome, localhost:4200
