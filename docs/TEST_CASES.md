# Тест-кейсы: Angular Todo App

## TC-01 — Добавление задачи с валидным названием

**Тип:** Позитивный  
**Приоритет:** Высокий

**Шаги:**
1. Открыть приложение `http://localhost:4200`
2. Ввести текст «Buy milk» в поле ввода
3. Нажать кнопку «Add»

**Ожидаемый результат:** Задача «Buy milk» появляется первой в списке, поле ввода очищается

---

## TC-02 — Добавление задачи нажатием Enter

**Тип:** Позитивный  
**Приоритет:** Средний

**Шаги:**
1. Открыть приложение
2. Ввести текст «Buy milk» в поле ввода
3. Нажать клавишу Enter

**Ожидаемый результат:** Задача добавлена, поле ввода очищается

---

## TC-03 — Отметка задачи как выполненной

**Тип:** Позитивный  
**Приоритет:** Высокий

**Шаги:**
1. Открыть приложение (задачи загружаются из API)
2. Нажать на чекбокс первой задачи

**Ожидаемый результат:** Текст задачи перечёркивается, чекбокс становится отмеченным

---

## TC-04 — Редактирование задачи

**Тип:** Позитивный  
**Приоритет:** Высокий

**Шаги:**
1. Открыть приложение
2. Нажать кнопку «Edit» у любой задачи
3. Изменить текст в поле редактирования
4. Нажать «Save»

**Ожидаемый результат:** Задача отображается с новым текстом, поле редактирования скрывается

---

## TC-05 — Удаление задачи

**Тип:** Позитивный  
**Приоритет:** Высокий

**Шаги:**
1. Открыть приложение
2. Запомнить название первой задачи
3. Нажать кнопку «Delete» у первой задачи

**Ожидаемый результат:** Задача исчезает из списка

---

## TC-06 — Фильтрация: только активные задачи

**Тип:** Позитивный  
**Приоритет:** Средний

**Шаги:**
1. Открыть приложение
2. Нажать кнопку фильтра «Active»

**Ожидаемый результат:** В списке отображаются только невыполненные задачи (без перечёркивания)

## TC-07 — Фильтрация: только выполненные задачи

**Тип:** Позитивный  
**Приоритет:** Средний

**Шаги:**
1. Открыть приложение
2. Нажать кнопку фильтра «Completed»

**Ожидаемый результат:** В списке отображаются только задачи с перечёркнутым текстом

---

## TC-08 — Попытка добавить пустую задачу

**Тип:** Негативный  
**Приоритет:** Высокий

**Шаги:**
1. Открыть приложение
2. Оставить поле ввода пустым
3. Нажать кнопку «Add»

**Ожидаемый результат:** Задача не добавляется, список не изменяется

---

## TC-09 — Попытка добавить задачу из одних пробелов

**Тип:** Негативный / Граничный случай  
**Приоритет:** Средний

**Шаги:**
1. Открыть приложение
2. Ввести в поле «   » (несколько пробелов)
3. Нажать кнопку «Add»

**Ожидаемый результат:** Задача не добавляется (код проверяет `title.trim()`)

---

## TC-10 — Задачи не сохраняются после перезагрузки (особенность API)

**Тип:** Edge-case API  
**Приоритет:** Средний

**Шаги:**
1. Открыть приложение
2. Добавить задачу «Test task»
3. Обновить страницу (F5)

**Ожидаемый результат:** Задача «Test task» отсутствует в списке — JSONPlaceholder не сохраняет данные между сессиями, список возвращается к исходным 10 задачам из API
